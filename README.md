# Digital Image Transmission with Morse Code Encryption 🔐📷

## Overview
This project implements a Raspberry Pi and Webcame as nodes for **Python-based secure digital image transmission system** for sending images over SSH. As an additional security layer, images are encrypted using Morse code before transmission.

## Features
- Image encoding into Morse code.
- Secure transmission over SSH.
- Decryption and image reconstruction at the receiver.
- Lightweight encryption suitable for constrained environments.

## Tech Stack
- **Language:** Python
- **Libraries:** Paramiko (SSH), OpenCV (image processing), custom Morse code module.

## Applications
- **Low Bandwidth Communication** because of Morse Code (Similar to BPSK) Encoding.
- **Secure Transmission**
- **Long Distance Communication** versatility that can easily be added by upgrading edge node hardware.
